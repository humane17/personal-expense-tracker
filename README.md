**Personal Expense Tracker**

A Personal Expense Tracker built with FastAPI, SQLAlchemy, and PostgreSQL. This app allows users to manually record their daily expenses, categorize them, and manage their financial data.

**Features**

CRUD operations for user and expense records.
Categorize expenses (e.g., Food, Transport, Emergency, Shopping).
Uses PostgreSQL for data storage.
Built with FastAPI for a fast and simple API.
SQLAlchemy for ORM-based database interaction.
JWT-based authentication for secure access to the API.

**Pending Features**

Recurring Expenses: Implement functionality to track recurring expenses (e.g., subscriptions, rent).
Notifications: Add notifications (email/SMS) to notify users about overspending or reminders for recurring payments.
UI : Django based UI functionality.

**Future Scope**

Third Party APIs : Integrating GPay API to semi-automate expense tracking.
